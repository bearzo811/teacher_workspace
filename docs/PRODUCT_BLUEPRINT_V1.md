## 產品定位

**一套圍繞老師一天工作流程的班級工作台。**

| 入口 | 角色 | 職責 |
|------|------|------|
| **Teacher Workspace** | 老師 | 管理、決策、輸入 |
| **Classroom Display**（`/display`） | 學生／全班 | 展示、提醒、自助完成 |

---

## 核心原則（最高優先）

1. **Today 是唯一高頻工作入口**：老師一天的高頻工作從 Today 開始。  
2. **資料只輸入一次**（例：聯絡簿 → 隔日作業）。  
3. **管理與工作分離**：學生中心、設定不進入日常主流程。  
4. **同一份資料，雙重呈現**：老師看待處理／未完成；學生看今天要做什麼／自己的狀態。  
5. **新功能三問**：屬於一天哪階段？老師還是學生工作？能否併入既有流程而非新平鋪頁？  
6. **點擊預算（硬規則）**  

> **任何高頻工作（每天至少一次）都不應超過三次點擊完成；任何低頻功能（學生管理、設定等）都不能干擾老師每天的工作流程。**

違反時：優先整合進 Today／既有流程，禁止再加平鋪高頻頁。

## 資訊架構（Sidebar）

```text
Today          ← 高頻唯一工作入口（原 Dashboard 升級）
聯絡簿
行事曆         ← 特殊活動／節日；同步大屏黑板
作業           ← 完整管理（含歷史）；Today「收作業」深鏈到今日
護照           ← 國語／英語（可分頁或子 nav）
閱讀總表       ← 讀報／閱讀心得（學期月份）
每日任務       ← 打掃／刷牙等（學生例行）
學生           ← 低頻
設定           ← 低頻
（大屏：書籤 /display，Sidebar 可保留次要入口）
```

## Today（工作狀態儀表板，非勾選清單）

### 呈現

項目顯示 **狀態**，不是另一份 checklist：

```text
🟢 收作業（42/42）
🟡 國語護照（39/42）
🔴 上午打掃（未確認）
🟢 編輯聯絡簿（已完成）
```

- 狀態隨資料自然變；打掃／刷牙／抄聯絡簿皆由大屏學生點選驅動，不需老師「確認完成」。

### 時段分組

| 時段 | 項目 |
|------|------|
| 到校 | 收作業、確認聯絡簿、上午打掃 |
| 白天 | 國語護照、英語護照、補交作業 |
| 中午 | 午餐刷牙、中午打掃 |
| 放學 | 編輯聯絡簿 |

### 完成方式（Hybrid｜已拍板）

**系統能判斷的自動完成；不能判斷的老師手動。**

| 項目 | 完成方式 | 自動條件（v1 定義） |
|------|----------|---------------------|
| 收作業 | 自動 | 今日**繳交日**作業：在籍生皆全交 |
| 確認聯絡簿 | 自動（僅大屏「已抄」全班） | 全班 `contact_book_copied`；**無老師手動確認** |
| 國語護照 | 自動 | **目前週**國語：在籍生皆 `completed` |
| 英語護照 | 自動 | **目前週**英語：在籍生皆 `completed` |
| 補交作業 | 自動 | 同收作業（或與收作業合併顯示——實作可合併為一項） |
| 上午打掃 | 自動（僅大屏） | 全班 `morning_cleaning`；**無老師手動確認** |
| 午餐刷牙 | 自動（僅大屏） | 全班 `lunch_brushing`；**無老師手動確認** |
| 中午打掃 | 自動（僅大屏） | 全班 `noon_cleaning`；**無老師手動確認** |
| 編輯聯絡簿 | 自動 | 今日聯絡簿**已儲存**（有存檔紀錄即可；允許空項目＋叮嚀） |

### 每項列上必有

- 完成率或狀態文案  
- 未完成人數／名單（適用者）  
- 【開始處理】深鏈

## 聯絡簿／作業／護照（對齊既有＋藍圖）

### 聯絡簿

編輯今日、模板、叮嚀、列印、自動建立**下一個上課日**繳交作業（`contact_book_date` ≠ `due date`）。

### 作業

- **Today「收作業」** → 深鏈作業頁（今日繳交）。  
- **獨立作業頁**：今日清單、勾選、缺交、歷史／補交／刪除。

### 護照（老師端）

國語／英語；全班矩陣；三態；週切換／歷史（頁內可切週，不完全依賴設定）。

### 大屏護照（已拍板｜2026-07-30 修訂）

| 操作 | 學生（選座號後、自己的格） | 老師 |
|------|---------------------------|------|
| 未開始／缺家長／完成 三態循環 | ✅（含他週，方便補缺） | ✅ |
| 改別人的格子 | ❌ | ✅ |

### 大屏面板（已拍板｜D1｜2026-07-30）

| 面板 | 內容 |
|------|------|
| **今日** | 左：聯絡簿；右：未選座＝五項進度條；選座後＝個人 checklist（左常規／右作業）；**不可改護照** |
| **護照總表** | 未選座：全班矩陣瀏覽；選座後：只顯示該生國語／英語橫欄（底部可點） |
| **閱讀** | 未選座：讀報＋心得雙矩陣；選座後：該生月份橫欄三態 |
| **行事曆** | 本月總覽＋未來倒數 |

獨立「進度」「個人完成」面板已刪除（進度併入今日右側）。

### 大屏兒童觸控 UX（2026-07-30）

- 頁面導覽與座號列固定在底部；座號單列橫向滑動，避免多列向上堆高。
- 觸控按鈕至少 56×56 px；選中座號使用高對比色。
- 「今日」個人 checklist 靠近畫面下半部。
- 護照：未選座看全班總表；選座後改為該生雙橫欄（國語／英語），大按鈕直接點週數。
- 學生操作期間暫停自動輪播，30 秒無操作才取消座號。

## 每日任務（新域）

v1 預設 key：`morning_cleaning`｜`lunch_brushing`｜`noon_cleaning`  

- 老師：Today 看大屏自助完成進度與未完成名單／歷史  
- 學生：大屏個人 checklist 可自助勾（設定開關）  
- 與老師 meta「今日工作」分離建模（學生例行 ≠ 老師收工狀態）

## Classroom Display

1. **今日**：黑板聯絡簿＋當日行事曆；右側未選座顯示五項進度，選座後個人 checklist。  
2. **護照總表**：雙護照矩陣；選座號後個人橫欄操作。  
3. **閱讀**：讀報＋閱讀心得雙矩陣；選座號後個人月份橫欄。  
4. **行事曆**：本月總覽＋未來活動倒數。

### 行事曆（2026-07-30）

- 獨立頁 `/calendar`：月曆總覽、倒數、選日新增／編輯／刪除。  
- 每筆可為**整天**或**時段**（開始必填、結束選填）。  
- 大屏黑板下方標題 `行事曆：`，僅顯示當天活動。  
- 大屏另有「行事曆」面板：本月總覽＋未來倒數。

### 閱讀總表（2026-07-30）

- 每月一篇**讀報**＋一篇**閱讀心得**；**1、2、7、8 月除外**。  
- 以學期為單位顯示：上學期 **9–12**、下學期 **3–6**。  
- 老師可設閱讀學年度＋上／下；未設閱讀學年時依月份自動建議（7–12→上；1–6→下）。  
- 三態同護照：未開始／缺家長／已完成。  
- 老師頁 `/reading`；大屏「閱讀」面板可點（設定開關）。

## 一天情境（摘要）

- **到校**：Today→收作業／確認聯絡簿；學生看大屏抄聯絡簿、交作業。  
- **下課**：Today→護照／補交；學生看自己還缺什麼。  
- **中午**：Today→打掃／刷牙確認；學生大屏自助。  
- **放學**：Today→編輯聯絡簿；學生抄聯絡簿。
