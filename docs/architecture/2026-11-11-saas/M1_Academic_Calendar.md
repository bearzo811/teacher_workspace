# 新版學期與上課日基礎

2026-11-12：已實作，本機驗證完成，雲端尚未啟用。

## 此次範圍

- 每班保留最多 30 個學期，可建立、修改、切換唯一啟用學期；不提供永久刪除。
- 起訖日可為任意星期，日期限 2000–2100，含首尾最多 367 天。第一學期自動啟用，後續需老師明確切換。
- 每日預設平日上課／週末放假，僅學期範圍內生效。可設定單日放假、補課及說明，或還原預設。
- 週次以開始日所在週為第一週，之後週一換週；假日與補課不移動週次。使用台灣時區取得今天，日期運算以 UTC date-only 避免伺服器時區偏移。
- 顯示月曆、學期狀態及下一上課日，後續聯絡簿與繳交日共用 calendar helper，尚未接入業務模組。
- 縮短日期範圍時，若例外日會落到學期外，拒絕儲存並說明先還原例外日，避免靜默遺失設定。

## 隔離與啟用

`0004_academic_calendar.sql` 僅供新版 Supabase。兩表 RLS、authenticated SELECT only，直接寫表與匿名存取禁止。四個公開限定函式與一個私有鎖定函式以有效 Google 老師及班級擁有權控管；修改及切換共用班級列鎖，唯一索引限制單一啟用學期。

`PILOT_CALENDAR_ENABLED` 預設 false。需要確認新版資料庫權限後才執行 migration，驗證後才能開啟環境開關與重新部署。舊站／舊資料庫不得變更。
