# 新版每日任務（老師端）

2026-11-17：功能開發階段，老師端雲端權限與功能開關已確認啟用。

- 四項既有一般上課日任務：上午打掃、抄聯絡簿、午餐刷牙、中午打掃。
- 頁面依班級啟用學期與行事曆判斷上課日；假日、學期外、未啟用學期不允許新寫入。學期任意起訖日、補課日均沿用月曆判斷。
- 出缺席永遠獨立記錄，任務只讀取該日請假狀態。請假者不列完成率分母與未完成名單，不接受任務更新，原完成紀錄不抹除、不自動完成；改回出席恢復原紀錄計算。未確認出缺席者明示暫按出席。
- 抄聯絡簿完成需要作業模組開啟且當日已有聯絡簿；其他三項不依賴作業模組。作業模組關閉後仍可取消舊抄寫紀錄。
- 班級／學期／學生 composite FK、RLS、有效老師與模組檢核、同班列鎖。函式接受目標完成狀態，不做不明確 toggle；重送不重複新增，也不刷新已完成時間。
- 總覽一次批次讀取四項，最多 15×4 筆；讀取失敗不出示統計或操作表單。完整未完成名單可換行。
- 日期隨表單回傳保留；儲存中停用按鈕並顯示待處理狀態。

## 本段邊界

只開發老師端記錄，不啟用匿名或學生大屏寫入，不發扣金幣或 XP。返校日及交暑假作業專屬設定尚未移植，不將學期外日期硬當作一般上課日，也不改變學期週次。歷史學期任務的獨立查閱入口及工作／任務自訂仍待後續階段。

切換學期、調整行事曆或關閉模組不刪除舊紀錄；被改為非上課日的舊紀錄保留但不能在此頁編輯，需恢復有效日後處理。不以本段代表完整生活模組已完成。

新增 migration 0010 僅供新版 Supabase；雲端執行前需明確確認教師管理自己班級每日任務的權限。`PILOT_ROUTINES_ENABLED` 預設 false，禁止先開旗標後跑 migration。

本機 16 項測試及 production build 通過，涵蓋跨班、模組關閉／重開保留、出缺席排除且保留完成、學期外／假日拒絕、補課日可用、抄聯絡簿依賴檢查、移除學生、停用老師、匿名／直接改表拒絕及重送完成時間不變。舊站完全不變。
