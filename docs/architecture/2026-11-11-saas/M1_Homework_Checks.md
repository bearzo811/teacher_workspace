# 新版老師端作業檢核

2026-11-16：本機完成，雲端待確認啟用。

- 作業表依繳交日載入，不是聯絡簿日期；不顯示移除的作業與學生。
- 四態：未交、待確認、未訂正完成、已完成；缺少檢核紀錄時視為未交。待確認／未訂正完成／已完成皆算已交，完成訂正則只有已完成。
- 每位學生每項作業以明確選擇並儲存更新，儲存中停用按鈕；錯誤不能冒充儲存成功。相同狀態重送採 upsert 不新增重複紀錄。
- 老師端可明確調整四態，學生自助入口尚未開放。
- homework 模組關閉、老師停用、跨班 assignment/student ID、已移除作業／學生皆由後端拒絕，不只隱藏按鈕。
- 班級／學生與班級／作業 composite FK 保證歸屬，RLS 僅有效同班老師可讀，匿名及直接改表禁止。
- 移除與復原不刪檢核歷史。簿本停用不讓既有作業變成永遠無法檢核。
- 查詢作業狀態按 50 項作業批次載入（每批最多 750 個使用中學生狀態），避免資料庫 API 截斷誤判未交；異常超量或讀取錯誤時不顯示可修改表單。

0008 只供新版資料庫。`PILOT_HOMEWORK_CHECKS_ENABLED` 預設 false，待雲端權限確認後執行 migration 再啟用。

本機新版 12 項測試與 production build 通過，含 SQL 整合案例：四態更新及重送、未知狀態拒絕、跨班學生／作業拒絕、已移除項目拒絕、移除復原保留紀錄、模組關閉與停用老師／匿名拒絕、直接改表拒絕。

尚待雲端實測、不同尺寸及負載驗收。尚未整合學生大屏、欠繳清單與金幣／XP，本次檢核不發放也不扣除獎勵。舊站不變。
