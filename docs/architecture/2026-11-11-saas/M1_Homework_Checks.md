- 作業表依繳交日載入，不是聯絡簿日期；不顯示移除的作業與學生。
- 四態：未交、待確認、未訂正完成、已完成；缺少檢核紀錄時視為未交。待確認／未訂正完成／已完成皆算已交，完成訂正則只有已完成。
- 每位學生每項作業以明確選擇並儲存更新，儲存中停用按鈕；錯誤不能冒充儲存成功。相同狀態重送採 upsert 不新增重複紀錄。
- 老師端可明確調整四態，學生自助入口尚未開放。

- 班級／學生與班級／作業 composite FK 保證歸屬，RLS 僅有效同班老師可讀，匿名及直接改表禁止。

- 查詢作業狀態按 50 項作業批次載入（每批最多 750 個使用中學生狀態），避免資料庫 API 截斷誤判未交；異常超量或讀取錯誤時不顯示可修改表單。
