# 個別學生作業清單

2026-11-17：沿用現有老師身分及 RLS，只讀取自己班級資料；不新增資料庫權限或 migration。

- 待完成總覽每位學生提供列印入口，保留所選學期、繳交日起與截止日。
- 只列尚未完成的作業：未交、待確認、未訂正完成；已完成、封存及範圍外作業不列。
- 明示目前僅包含作業，護照、閱讀／讀報尚未移植，不以此清單冒充完整欠繳名單。
- 包含學生身分、範圍、作業內容、目前狀態與自查方格；不加入聯絡簿日期欄或老師確認欄。
- A4 列印樣式、重複表頭、避免單列跨頁；提供系統列印／另存 PDF。
- UUID、日期、未來截止日與順序驗證；同班有效學生／學期查核。查詢錯誤、模組關閉及超過 1000 項皆不顯示可列印清單，避免漏列。
