# 白板背包與使用申請（2026-11-23）

0029：有效配對白板可先選學生，再讀取該學生所有永久獎品（含終態）。每頁 50、最多 20 頁，依建立時間及 ID 穩定排序。模組關閉不傳名冊與獎品；未選學生不傳背包。

學生只有 available→requested 權限，不提供自行核銷、退回、撤回、贈送、退款。已申請等待老師處理；老師沿用既有退回／核銷功能。贈品與已購獎品皆適用，商店關閉或有欠繳不影響既有獎品提出申請。

班級由憑證決定，鎖定班級後重驗授權；驗證本班有效學生及該生的獎品、版本、狀態。UUID 請求重送僅回原結果，衝突拒絕。變更狀態和 history 同交易；歷史保存 device_id、actor_kind=device，老師專用 RPC 不授權給匿名裝置。不變更金幣／XP／庫存。

完整 29 測試及 build 通過，包含不同學生／跨班拒絕、已核銷不可申請、重送、衝突、分頁、故障回滾、贈品與已購獎品、匿名無核銷權限、模組關閉與撤銷失效。雲端啟用與 UI 驗收另行記錄。其他大屏分頁、實體白板字級與完整 RWD 尚未完成。
