# 護照每日逾期扣點（本機完成，雲端待授權）

2026-11-19。僅新版 pilot；使用者已確認「請假當天免扣」。尚未執行 0020／0021，沒有雲端扣款或排程。

## 功能與界線

- 0020 建立班級獨立開關、護照完成狀態歷史、扣款來源關聯及每班每日結算收據。`PILOT_PASSPORT_OVERDUE_ENABLED` 預設 false，老師另行確認啟用。
- 0021 是需額外授權的雲端 pg_cron 設定；每日 UTC 16:05（台灣翌日 00:05），在資料庫內直接呼叫私有 worker，不使用 HTTP、service-role key 或新密鑰。不碰舊站。排程時區不是 UTC 時拒絕建立；同名但不同命令／擁有者不覆寫。
- 只結算台灣昨天，不補掃歷史。第一輪啟用日起算，停用期間不扣，重開以新啟用日重新起算。
- 只處理啟用學期、仍使用的護照與學生；每本每週每天一筆。當週尚未完成不扣，只扣先前週次。
- 依月曆上課日：一般週末／放假不扣、補課日扣；結算時已登記當日請假者免扣，未點名暫按出席。
- 依該日台灣午夜前的完成歷史判斷。午夜後完成或取消不能改寫前一天狀態。基線在 migration 記錄當前狀態，非補發獎勵；新啟用日不早於此基線。
- 金額採結算時確認的規則版本，版本及逐項帳本可追溯。只扣金幣，不扣 XP。淨額可負，可用金幣顯示最低 0。
- 結算後補登請假／修改過去狀態不自動追溯改帳；可由老師以現有帳本反向調整。這項限制在設定頁明示。
- 班級列鎖＋來源唯一鍵＋成功收據使重跑不重扣。單班扣款整批交易，失敗整批回滾；私有 worker 將失敗碼保留，繼續其他班，當天可由維運重試。錯過的舊日期不自動補扣。
- 背景函式不授權 anonymous／authenticated；老師僅可設定自己班級、查看自己班級結算收據與扣款來源。已停用老師、移除班級或關閉相關模組不執行。

## 驗收

本機 SQL 測試：預設不扣、規則未確認拒絕、無歷史追扣、當週不扣、逐日來源唯一、請假／週末／放假／補課、午夜前後狀態、負淨額不改 XP、第二項故障時整班回滾、失敗重試、停用與重新啟用不補扣、停用老師、匿名與跨班禁止。

PGlite 不提供 pg_cron；0021 尚無真實排程驗收。不能把本機 worker 測試通過宣稱排程已上線，更不能宣稱已觀察自然觸發扣款。設定頁提供最近 30 日每班收據，不代替平台整體告警／備份監控。
