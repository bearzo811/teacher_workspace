# 班級暫停與復原（0043）

2026-11-26：本機程式與隔離測試完成，雲端尚未套用、PILOT_CLASS_PAUSE_ENABLED 預設關閉。新增老師管理自己班級狀態的權限已提出當次確認，尚不宣稱可在線上操作。

暫停在單一交易內撤銷有效白板與未使用配對碼、關閉商店（保留設定版本歷史）、關閉五類自動獎勵／逾期設定，再設定班級 deleted_at。沿用所有業務權限與扣點排程對 deleted_at 的拒絕；不刪業務資料、不發扣點、不改背包。

復原只清除班級 deleted_at，舊白板永不因復原重新生效；商店、自動獎勵與扣點仍關閉，需要老師另行確認。復原與建班使用同一老師鎖，有另一個使用中班級時拒絕。這是可逆暫停，不是 30 天刪除／到期清除或帳號刪除，沒有承諾清除期限。

後續若加入真正的刪除與到期清除，必須另有明確刪除意圖與狀態，不能僅依 deleted_at 非空就清除本功能暫停的班級。

每次操作具請求 UUID、預期狀態時間、原因及老師確認；相同請求重送不再改動，原因或目標不一致則拒絕，舊暫停請求重送不能撤回後來的復原。私有 class_lifecycle_events 保留操作紀錄，普通角色不可直接讀寫；它屬安全操作稽核，不加入現有業務資料匯出（不改 0042 業務快照格式）。

本機 SQL 驗證：跨班／匿名拒絕、名冊與業務讀取停止、白板及未用配對碼失效、模組已關閉仍可安全關商店、排程跳過、復原衝突與過期時間拒絕、重送冪等、復原後舊裝置仍拒絕、帳本不變。50 項全套測試及 build 通過。尚待雲端操作、並行壓力及整合驗收。
