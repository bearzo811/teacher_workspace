# 大屏配對基礎（2026-11-23）

範圍：老師建立／撤銷自己班級裝置；白板使用一次性碼取得 HttpOnly 授權 cookie，重開可續用。此階段只傳回班級名稱，尚未開放學生資料、自助操作、購買或大屏六分頁。

後續狀態：0027／0028 已接上配對白板商店與直接購買，詳見 M2_Display_Shop.md。其餘大屏分頁尚未完成；本文件下列僅描述配對基礎階段的驗收。

工程預設：配對碼採 122 位元隨機 UUID 去除連字號，10 分鐘、一次使用；裝置 token 為兩組隨機 UUID（244 位元），90 天，每班同時最多 5 台有效／等待配對裝置，最多保留 200 筆歷史。只存 SHA-256 雜湊，原碼僅建立時回傳，老師查詢欄位不含雜湊。憑證不進網址，cookie 限 /display、HttpOnly、SameSite Strict、production Secure。撤銷保留歷史日期。

資料庫班級鎖與裝置鎖順序一致；兌換後清除配對碼雜湊，不能重用。班級刪除、老師停用、裝置撤銷或到期都拒絕。教師與白板使用不同客戶端，白板 RPC 不借用老師登入。匿名無法讀裝置表、建立配對碼或撤銷裝置；有效裝置僅能取得其所屬班級名稱，沒有可指定其他班級的參數。

測試包含一次性使用、無效碼、到期碼、到期 token、撤銷、停用老師、跨班、匿名、雜湊欄位不可讀、5 台上限。完整 29 測試及建置通過。真實並行壓力、完整學生白名單及端到端大屏流程仍待完成。
