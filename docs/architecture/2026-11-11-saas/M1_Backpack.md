# 老師端永久背包（本機完成，雲端待授權）

2026-11-19。0023、`/workspace/backpacks`，`PILOT_BACKPACK_ENABLED=false`。未執行雲端 migration。

## 本階段範圍

- 每一份獎品獨立 ID；永久有效，沒有到期日。一學生最多保留 1000 份，包含已使用、已撤回；不是無限數量。
- 老師從使用中商品贈送一份給自己班級的使用中學生。不扣金幣、不減庫存、不受等級及欠繳限制，沿用舊站贈送語意。
- 保存名稱、圖示、種類與說明快照；商品日後修改或下架不改寫已持有獎品。來源與實付金幣獨立保存，贈品實付必為 0。
- 使用流程沿用舊站：available→requested→redeemed；requested 可退回 available。老師端提供「代登使用申請」，不冒稱是學生本人申請；各紀錄 actor 是老師。
- available／requested 可撤回為 revoked；已使用、已撤回為終態，不能復活，也不永久刪除。下架商品的已持有贈品仍可使用。
- 贈送與管理每次都有 request UUID；同一請求重送不重複，多份同名贈品必須用不同新請求。版本避免舊分頁覆蓋，操作須填原因並確認。
- 獎品及狀態與稽核紀錄同一交易；紀錄寫入失敗整筆回滾。歷史無直接寫表／刪除權限，同一獎品版本唯一。
- 按學生查閱、每頁 50 份，最多 20 頁；明示總數及頁碼。每份獎品可查看最新 50 筆操作紀錄，並非宣稱畫面顯示全部永久歷史。
- 移除學生不刪背包，但不允許新贈送／管理；本階段 UI 只提供使用中學生入口，歷史學生查閱仍待後續。
- 這次只處理 gift 來源；沒有購買、退款、實際商品核銷之外的自動作業減量／影音點播或學生裝置 API。資料表為後續購買預留 source，但老師管理函式拒絕 purchase，不能繞過未實作的退款規則。

## 安全與驗證

班級列鎖、同班複合外鍵、RLS 與有效 Google 老師；匿名、跨班、停用帳號／模組、移除學生、直接寫表皆拒絕。無 service-role key。

29 項新版測試與 production build 通過（含多案例 SQL 整合）。涵蓋贈品不改金幣／XP／庫存、請求冪等與衝突、版本與合法轉態、終態、商品快照、下架仍可管理、故障時原子回滾、容量及資料隔離。尚未進行雲端 UI、多尺寸或真正併發負載驗收，不宣稱學生背包完整上線。
