# 新版多班級試用專案：總目標與完成盤點

盤點日期：2026-11-19（台灣）｜程式基準：4180b77｜範圍：`pilot/` 新版，不把舊單班站實作直接計入。

## 結論與計數口徑

原計畫為 **6 個里程碑（M0～M5）**；「20 項決策」不是 20 個開發待辦。原計畫沒有細項總數。本次將首版保留範圍、里程碑及已確認保留功能整理成 **53 個可核對交付單位**：**26 項核心完成、7 項部分完成、20 項未完成**。

26／53 ≈ **49% 是等權項目完成比例，不是工期或工時完成率**。大屏、購買交易、備份等未完成項目可能比單一老師端表單更大；不能解讀為只剩一半時間。

「核心完成」：該列明確範圍已實作並有測試／部署驗收紀錄；不表示全產品 UX、RWD、真實班級可上線。這些另列整合項目。雲端狀態依截至 11/18 的既有驗收紀錄，本次未重新登入雲端或變更任何權限。

## 里程碑判讀

- M0 獨立環境：主要隔離已落地，但完整舊站回歸仍未全部驗收，因此不宣稱整個 M0 發布門檻通過。
- M1 身分與全領域資料隔離：老師端基礎完成較多；商店、背包、排程等未移植，完整里程碑尚未完成。
- M2 裝置配對／學生權限：未完成。
- M3 引導／自訂值日／小班 RWD：部分基礎已做，整體未完成。
- M4 備份／隱私／生命週期：未完成。
- M5 全流程整合／多人試用：未完成。

**目前沒有任何一個里程碑已被完整 Release Gate 簽核。新版仍是開發／虛構資料驗收站，不能當成正式多人產品。**
