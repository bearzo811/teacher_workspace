# 新版護照老師端

2026-11-17：本機功能完成、17 項測試及 production build 通過；使用者確認後已啟用老師端雲端權限。

- 老師自行建立護照名稱及第幾週開始／結束，不預設每個學校都有國英護照。
- 每學期最多保留 20 本（含停用）；有效名稱不可重複，週次限 1～25 且建立時不超過學期的最後週。學期週次沿用任意起始日期、週一換週的規則。
- 兩種狀態：未開始、已完成。可提前完成；取消後回到未開始，不建立第三態。
- 以學期歸屬護照、以護照／學生／週次唯一鍵保存紀錄。重送相同狀態不重複新增、不刷新既有完成時間。
- 限有效 Google 老師、自己的使用中班級、開啟護照模組、啟用學期及使用中學生；資料表 RLS、同班 composite FK、限定函式與班級列鎖。
- 停用可復原，保留歷史；模組關閉不刪資料且停止讀寫。出缺席不自動改變每週護照完成狀態。
- 完成矩陣橫向滾動限制在表格，姓名座號固定左側；每本最多查 25×15 筆，分批限制並行，避免 PostgREST 1000 筆截斷。查詢錯誤不顯示矩陣與編輯表單。
