# 新版返校日

返校日與學期、月曆上課日分開，不更動起訖、週次與作業繳交日。僅包含上午打掃及交暑假作業，出缺席獨立管理。此階段只開放老師記錄，不涉及金幣、XP 或學生大屏。

## 邊界

- 每班最多保留 60 個日期；停用保留完成紀錄。
- 啟用學期的上課日優先使用一般每日任務，不可同時寫返校任務。
- 日後月曆改為上課日，原返校紀錄仍保留，但停止返校任務寫入。
- 請假學生不計入當日任務分母，不能修改其完成狀態，原紀錄不刪除。
- 僅啟用每日任務模組的班級可操作。老師只能讀寫自己班級；匿名、跨班、封存學生與直接資料表寫入均禁止。
- 重複送出完成不重建紀錄或改動首次完成時間；取消後清除完成時間。
