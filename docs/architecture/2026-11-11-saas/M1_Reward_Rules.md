# 每班獨立獎勵規則

`/workspace/rewards/rules`，`PILOT_REWARD_RULES_ENABLED` 預設 false。0015 只保存老師確認後的數值與版本，沒有自動加扣、歷史追補或改寫手動帳本。

15 個明確數值欄位沿用目前規則範本：作業準時／遲交／未交、護照提早及週一到五、護照逾週每上課日扣點、讀報／心得、生活任務金幣及 XP、升級基數、代班確認金幣。老師必須檢查並勾選確認，不預設代替同意。

值域：非負獎勵 0–10000、扣點 -10000–0、升級基數 1–10000，全部整數；護照週一到週五不可遞增。前端及 SQL 同時驗證完整 15 鍵、拒絕額外鍵、缺鍵、字串數字及小數。

每班列鎖及 expected_version 避免多分頁覆寫；相同規則重送不增加版本。每版不可修改或刪除，最多 1000 版，頁面展示最近 20 版詳細數值。模組關閉隱藏但保留歷史。

本機 24 項測試及 build 通過，含 A／C 跨班、匿名、停用老師、版本衝突、重送、不可直接 DML 及保存規則不增加帳本。2026-11-18 使用者已同意新增老師自己班級規則權限；雲端部署與驗收進行中，不代表自動獎勵已開啟。
