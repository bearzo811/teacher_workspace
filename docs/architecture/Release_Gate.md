### 上線風險與決策

- P1 仍開放：大屏免登入，任何取得 `/display` 網址的人仍可能呼叫學生寫入 API。
- 教師密碼改為 `admin` 已依需求完成，但這是非常弱的密碼；請勿分享後台網址，也不要在非受控裝置保存登入狀態。
- 閱讀／讀報目前將「當月尚未完成」視為欠繳。9 月第一天可能讓學生立刻被標為有欠繳並封鎖商店／下課；這是規則選擇，建議改為「月底後才列欠繳」再正式啟用封鎖。
